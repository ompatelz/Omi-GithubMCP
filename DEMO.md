# RepoPilot demo

1. Open the README architecture diagram and explain the MCP host/client/server flow.
2. Connect RepoPilot using `mcp-config.example.json` and show discovered tools.
3. Ask the client to list a repository directory, then retrieve a known source file.
4. Inspect an issue and a pull request, including changed-file metadata.
5. With explicit approval and a scoped token, create a clearly marked test issue
   and add one comment; confirm both in GitHub.
6. Show `evaluation_cases.json` and explain that results must be recorded rather
   than invented.

Never demonstrate a real write action against an unintended repository.
